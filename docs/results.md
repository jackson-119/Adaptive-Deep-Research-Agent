## 已确认的评分局限

两组写作证据均包含路由函数读取 state、默认将返回值用作下一节点名称的原文。按当前评估检索函数回放时，两组覆盖评估输入都遗漏了这段话，随后 routing 被判为 partial。

Baseline 的“节点只需返回部分更新”在覆盖评估中 supported，在声明核验中 insufficient；两个判断使用的片段不同。这个差异首先要求检查证据选择，不能直接说明报告事实错误或声明核验模型一定错误。

两组覆盖评估及声明核验均首次成功，未触发重试。当前结果只能说明本次评估完整，不能验证失败恢复成功率。模型判为 supported 也不等同于人工确认。

## 实验结论与下一步

最新单次实验中，Event 的 Token 比 Baseline 多约 94.9%，耗时多约 63.5%；自动覆盖率相同，声明支持率较高，但报告的声明集合不同。结合评分证据偏差和单次样本，尚不能确认 Event 带来研究质量提升。

先修复并校准评估证据一致性，再以相同模型、计划、预算和版本执行多任务重复实验。获得足够样本后再绘制均值 Token 与覆盖率的质量—成本图，同时展示波动和未完成比例；本次不以两个单点生成暗示稳健收益的曲线。
