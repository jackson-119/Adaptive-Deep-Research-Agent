# 路线

已完成研究原型 v2 的主流程重构：动态研究控制、全局原文检索、独立写作与事后报告评价、单报告重评、批量真实任务入口。历史任务轮转与在线全量覆盖评分退出生产路径。

下一阶段以真实任务验收为先：

1. 固定 LangGraph 简报与 3–5 个问题，各重复运行并人工校准报告评分。
2. 根据失败样本判断是否需要混合向量检索、reranker 或结构化文档解析；不因单一 LangGraph 样例不断堆特例。
3. 增加声明级引用蕴含校验、检索与报告质量的独立指标。
4. 当任务规模证明确有需要，再加入持久化索引、故障恢复和受预算约束的并行研究者。

SFT/GRPO、训练数据和 Ascend 本地推理不在当前验收范围。不要把通过回归测试等同于算法或研究质量收益已被证明。
