## BM25 的具体定义

文档是 1200 字符窗口，步长 900。英文/API 标识符用小写词项，中文使用重叠双字词项，均保留出现次数。长度为 token 数。取 k1=1.2、b=0.75：

```
idf(t) = log(1 + (N - df(t) + 0.5) / (df(t) + 0.5))
score(q,d) = sum(idf(t) * tf(t,d) * (k1+1)
                 / (tf(t,d) + k1*(1-b+b*len(d)/avgdl)))
```

查询词去重，不做 query-TF 加权。参考 [rank_bm25 的词频和长度处理](https://github.com/dorianbrown/rank_bm25/blob/master/rank_bm25.py)，但其 Okapi 默认 IDF 使用负值截断，本实现明确采用正 IDF 变体，分数不应声称与该库默认值逐位相同。版本标识 `bm25_tf_v2`。

## 目标状态与反思不是最终评分

目标 status 是模型的暂定判断。partial/supported 必须有引用，conflicted 至少有两段不同引文；机械校验仅证明引用存在，不能证明推理正确。supported 不允许同时保留未解决事实。未评估和无效引文不会被当作已支持。

反思最多 3 次（可配置），每个步骤最多一次。半程事件只触发一次，停滞事件需间隔至少两步；always 组仍受次数上限。反思需保留下一决策和写作额度。反馈只调整行动，不改验收标准，不写入最终评分字段。

疑似冲突来自研究者的结构化 `suspected_conflict` 标记，不是自动检测到的事实。所有工具和原文内容均为不可信证据。

## 暂不实现的项目

- 信息增益/净收益预测：尚无独立校准数据，不让 LLM 随意生成一个数字就驱动停止。
- Dense/RRF/reranker：先验证修正的词法基线，之后按失败样例决定是否加入。
- 50 题独立评测集：当前仍是 5 个文档开发问题，缺少独立参考答案与人工标签；不能把自动生成题目冒充已验证 benchmark。
- SFT/GRPO：没有启动训练。当前轨迹没有行为策略 log-prob，不能直接当作合法的 GRPO 训练批次。
- 持久化恢复与并行研究：后续工程工作。

本轮测试验证实现约束，不提供新的在线质量结果；消融收益必须由真实实验和人工复核确认。
